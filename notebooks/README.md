# Laboratorio de Experimentación Técnica

Esta carpeta contiene la guía para el desarrollo de Jupyter Notebooks utilizados en las fases de investigación y validación del modelo institucional.

## Flujo de Trabajo Técnico:
1. **01_Análisis_Exploratorio.ipynb**: Visualización de tendencias en el repositorio institucional y detección de correlaciones de riesgo.
2. **02_Preparación_de_Datos.ipynb**: Normalización y codificación de las 23 variables oficiales.
3. **03_Desarrollo_Predictivo.ipynb**: Comparación de algoritmos de clasificación para optimizar la fiabilidad del SAT.
4. **04_Validación_Institucional.ipynb**: Pruebas de estrés del modelo y validación de métricas de precisión.

*Nota: El Dashboard Ejecutivo (`app/main.py`) integra estas fases de forma automatizada para facilitar la gestión directiva.*
